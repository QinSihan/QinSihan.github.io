Zotero Paper Partner

个人项目 · JavaScript · Zotero 插件

GitHub下载

读论文时，有时只是一个概念没弄明白，却要切换到聊天窗口、复制上下文，再等一个回答。Zotero Paper Partner 把提问这一步留在笔记里：写下问题后继续阅读，回答会直接补到问题下方。

怎么使用

  • 在正在编辑的 Zotero 笔记中，以 Q: 开头写下问题，按回车后继续阅读。
  • 插件结合笔记中的上下文，在后台生成回答，再将回答写到问题下方。
  • 引用、问题和回答保留在同一份普通笔记里，可以继续编辑和整理。

为什么这样设计

我希望提问能融入原有的阅读习惯。遇到不懂的地方时，可以先记下问题，不必马上中断阅读；回头再看，相关引用和回答已经放在一起。

如果在等待回答时修改了上下文，插件会把旧结果标记为过期；请求失败时，也会显示错误状态。这样可以避免把基于旧内容生成的回答误当成当前答案。

安装与配置

从 Releases 下载 paper-partner.xpi，在 Zotero 的“工具 → 插件”中选择“从文件安装插件”。随后在 Paper Partner 设置中填入 API key、接口地址和模型名称，支持 OpenAI 兼容接口。

开发与复现

这个项目约 99% 通过 Vibe Coding 完成。除了源码，我还公开了原始 prompt 和设计说明（Open Prompt），保存在 target.md 中。其他人可以将这份文件交给 coding agent 复现，也可以在此基础上继续扩展。仓库同时提供打包说明。

Cyberpunk Recon

C++ · OpenGL · 团队课程项目

GitHub

这是一个用 C++ 和 OpenGL 开发的第一人称探索游戏原型。玩家需要在 90 秒内，在赛博朋克城市中寻找并扫描红色异常信号。扫描远处目标前，需要先用鼠标滚轮拉近画面。

项目内容

项目整合了场景加载、渲染、相机控制、输入处理、目标扫描和游戏界面。城市模型通过 Assimp 加载，画面包含随距离变化的雾效和故障风格的后处理效果（glitch）；任务说明、倒计时、计分和重新开始等界面使用 Dear ImGui 实现。

我的工作

  • 搭建项目框架与依赖环境，实现相机移动、视角控制和输入处理。
  • 与队友共同完成模型加载、场景渲染，以及部分界面和游戏逻辑。
  • 整合团队开发的模块，使渲染、交互和任务流程能够一起运行。

这是一个以图形学和交互为重点的课程项目，碰撞与命中判定采用了简化实现。具体分工和开发过程记录在仓库的 开发日志 中。
